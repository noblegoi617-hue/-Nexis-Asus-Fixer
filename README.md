Nexis Asus Fixer (Nexis Repair Tool) is a specialized, automated utility designed to permanently resolve the notorious WiFi and Bluetooth disappearing issues on ASUS laptops. Built with a premium GUI, it seamlessly diagnoses, resets, and installs the necessary drivers without requiring complex manual troubleshooting.

---

## 🔥 Key Features

*   **📦 Advanced Main File Extraction Method:** The tool uses a smart extraction mechanism embedded directly within the main file. It securely unpacks required driver files and scripts directly into the system's temporary directory for execution, ensuring a clean and error-free installation.
*   **📶 Auto-Driver Recovery:** Instantly reinstalls and resets corrupted Asus WiFi (MediaTek/Intel) and Bluetooth drivers.
*   **⚡ 1-Click Repair Engine:** No more messing around in the Device Manager. Fix your network issues with a single click.
*   **🧹 Registry & Network Reset:** Automatically flushes DNS, resets Winsock, and clears conflicting network registry entries to prevent the issue from returning.
*   **💻 Premium UI:** Powered by Guna UI for a sleek, modern, and user-friendly experience.
*   **🔒 Safe & Portable:** Does not install bloatware. All background operations are transparent and optimized for Windows 10/11.

## 🚀 How to Use

1. Go to the **Releases** tab and download the latest version of the tool.
2. **Important:** Extract the entire downloaded `.zip` folder. Do not run the `.exe` directly from inside the zip.
3. Keep all files (including the `runtimes` folder and `.dll` files like `Guna.UI2.dll`) in the **same folder**.
4. Right-click on **`Nexis Repair Tool.exe`** and select **Run as Administrator** (Admin rights are required to install system drivers).
5. Click the **Fix Network/Bluetooth** button and let the internal extraction engine do its magic!
6. Restart your PC when prompted.

---

## ⚙️ How the Extraction Method Works

Instead of forcing users to download multiple heavy driver packages manually, Nexis Asus Fixer holds the optimized, working versions of the network drivers compressed inside its core. Upon execution, the **Main File Extraction Method** safely unpacks these assets in the background, applies the fix, and cleans up after itself, leaving zero junk files on your hard drive.
